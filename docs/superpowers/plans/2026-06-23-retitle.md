# Periodic Session Title Refresh Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every 5 user messages, fire-and-forget a haiku call that decides whether to update `sessions.prompt` based on the last 10 log entries. Failure preserves the existing title.

**Architecture:** A new function `title::maybe_retitle(bin, current_title, recent_messages, env, cwd) -> Option<String>` parses the last 10 user/assistant entries from `Store::read_log`, spawns `claude -p --model haiku --max-turns 1` with a JSON-output system prompt, validates the result through the existing `is_valid_title` helper. A small helper `Engine::maybe_retitle_session(&self, id)` reads the log, calls `maybe_retitle`, and writes the new title on success. The `follow_up` path triggers it as a `tokio::spawn` background task whenever the just-incremented turn count is a multiple of 5 and a new `retitle_enabled` config flag is set. A new `EngineConfig.retitle_enabled: bool` (default true) provides the kill switch.

**Tech Stack:** Rust (tokio, std process spawn), shell test fixtures in `server-rs/tests/fixtures/`, `sqlx` for the existing `SessionPatch.prompt` write. No new dependencies. No new DB column.

## Global Constraints

- **Failure = silent fallback**: any error path in `maybe_retitle` MUST leave `sessions.prompt` exactly as it was. The user sees the same behaviour as the previous title.
- **Fire-and-forget**: the retitle task MUST be `tokio::spawn`-ed from `follow_up`; the API call must not block on it. Title changes are silent (no subscriber events).
- **Trigger gate**: retitle attempt happens iff `cfg.retitle_enabled` is true AND the turn count after increment is a positive multiple of 5 (5, 10, 15, …). Disabled = no task spawned, no subprocess started.
- **Test isolation**: no test hits the real `claude` binary; all tests use scripts in `server-rs/tests/fixtures/`. `make test` (= `cd server-rs && cargo test`) must stay green before each commit.
- **Engine purity**: `server-rs/src/engine/` stays free of axum imports. The new code lives in `engine/title.rs` and edits to `engine/mod.rs` are limited to the retitle trigger block.
- **No new DB column**: title writes go through the existing `SessionPatch.prompt` field on `sessions`.
- **No new dependencies**: use `tokio::process::Command` (already in tree) for the retitle subprocess.
- **Output rules**: parsed `{"change": false}` → return None; `{"change": true, "title": "..."}` → the title must pass `is_valid_title` (≤24 chars, no leading `#`/`>`/`` ` ``, no newlines) AND differ from the current title, otherwise → return None.
- **Timeout**: retitle MUST hard-cap at 5 seconds (`tokio::time::timeout`). On timeout → None.
- **Bounded prompt size**: at most 10 log entries AND at most 4 KiB of joined body text are fed to haiku. Older entries are dropped first when the cap is hit.

```rust
const RECENT_MESSAGES_MAX: usize = 10;
const RECENT_MESSAGES_MAX_BYTES: usize = 4 * 1024;

/// Parse the session's JSONL log lines into (role, text) pairs for the most
/// recent user/assistant messages. Capped at 10 entries and 4 KiB of joined
/// body text. Older entries are dropped first when the cap is hit, so the
/// returned list always reflects the tail of the conversation.
pub(crate) fn parse_recent_messages(lines: &[String]) -> Vec<(String, String)> {
    use serde_json::Value;
    let mut parsed: Vec<(String, String)> = Vec::new();
    for line in lines {
        let Ok(v) = serde_json::from_str::<Value>(line) else { continue };
        let Some(ty) = v.get("type").and_then(|t| t.as_str()) else { continue };
        match ty {
            "agentic_prompt" => {
                if let Some(text) = v.get("text").and_then(|t| t.as_str()) {
                    parsed.push(("user".to_string(), text.to_string()));
                }
            }
            "stream_event" => {
                // text_delta inside stream_event deltas
                if let Some(text) = v
                    .pointer("/event/delta/text")
                    .and_then(|t| t.as_str())
                {
                    parsed.push(("assistant".to_string(), text.to_string()));
                }
            }
            // For completed assistant text events emitted as standalone objects,
            // the on-wire format is the same: {"type":"...","text":"..."} or
            // {"type":"text","text":"..."}. Cover both shapes:
            "text" | "assistant_text" => {
                if let Some(text) = v.get("text").and_then(|t| t.as_str()) {
                    parsed.push(("assistant".to_string(), text.to_string()));
                }
            }
            _ => {}
        }
    }
    // Cap at 10 entries: keep the tail.
    if parsed.len() > RECENT_MESSAGES_MAX {
        let drop = parsed.len() - RECENT_MESSAGES_MAX;
        parsed.drain(..drop);
    }
    // Cap at 4 KiB of joined text: drop oldest until under the cap.
    while parsed.len() > 1 {
        let total: usize = parsed.iter().map(|(_, t)| t.len()).sum();
        if total <= RECENT_MESSAGES_MAX_BYTES { break; }
        parsed.remove(0);
    }
    parsed
}
```

```rust
    current_title: &str,
    recent_messages: &[(String, String)],
    env: &HashMap<String, String>,
    cwd: &Path,
) -> Option<String> {
    // Build the prompt body: header + current title + last 10 messages.
    let mut body = format!("当前标题: {current_title}\n\n最近消息:\n");
    for (role, text) in recent_messages {
        body.push_str(&format!("- {role}: {text}\n"));
    }

    let mut child = Command::new(bin)
        .arg("-p")
        .arg("--model").arg("haiku")
        .arg("--max-turns").arg("1")
        .arg("--system-prompt").arg(RETITLE_SYSTEM_PROMPT)
        .arg("--output-format").arg("text")
        .current_dir(cwd)
        .envs(env.iter().map(|(k, v)| (k.as_str(), v.as_str())))
        .stdin(Stdio::piped())
        .stdout(Stdio::piped())
        .stderr(Stdio::piped())
        .spawn()
        .ok()?;

    if let Some(mut stdin) = child.stdin.take() {
        let _ = stdin.write_all(body.as_bytes()).await;
        let _ = stdin.shutdown().await;
    }

    let output = tokio::time::timeout(TITLE_TIMEOUT, child.wait_with_output()).await.ok()??;
    if !output.status.success() { return None; }
    let stdout = String::from_utf8_lossy(&output.stdout);
    let trimmed = stdout.trim();
    if trimmed.is_empty() { return None; }

    // Parse the JSON. Accept either `{"change": true, "title": "..."}` or `{"change": false}`.
    let v: serde_json::Value = match serde_json::from_str(trimmed) {
        Ok(v) => v,
        Err(_) => return None,
    };
    let change = v.get("change").and_then(|c| c.as_bool()).unwrap_or(false);
    if !change { return None; }
    let Some(new_title) = v.get("title").and_then(|t| t.as_str()) else { return None };
    if new_title == current_title { return None; }
    if !is_valid_title(new_title) { return None; }
    Some(new_title.to_string())
}
```

The constants `TITLE_TIMEOUT`, `is_valid_title`, and the `Command` / `Stdio` / `AsyncWriteExt` imports are already at the top of `title.rs` from the previous spec's implementation. No new imports needed.

```rust
    /// Read the session's log, build the recent-message list, and call
    /// `title::maybe_retitle`. On success, write the new title to
    /// `sessions.prompt` via `SessionPatch`. On every failure path, leave
    /// the title unchanged. This is fire-and-forget — `follow_up` calls
    /// it from a `tokio::spawn` so the API handler does not block.
    pub async fn maybe_retitle_session(&self, id: &str) -> Option<String> {
        let lines = self.0.store.read_log(id);
        let recent = crate::engine::title::parse_recent_messages(&lines);
        let current = self.0.store.get(id).await.ok().flatten()?.prompt;
        let cwd = self.0.cfg.worktrees_root.join(id);
        let new_title = crate::engine::title::maybe_retitle(
            &self.0.cfg.title_bin,
            &current,
            &recent,
            &HashMap::new(),
            &cwd,
        ).await?;
        if let Err(e) = self.0.store.update(id, crate::engine::store::SessionPatch {
            prompt: Some(new_title.clone()),
            ..Default::default()
        }).await {
            tracing::warn!("[engine] retitle store.update failed: {e}");
        }
        Some(new_title)
    }
```
